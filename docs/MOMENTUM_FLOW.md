# 動能流程（探索 › 動能流程）

2026-10-09 新增的獨立功能：大盤狀態 → 候選池 → 檢查清單 → 組合試算 → 持股條件監看 → 流程回測與濾網效度。
程式碼只在 `pipeline/momentum_flow/`（計算）與 `web/src/momentum/`（頁面）；資料寫到資料分支 `momentum_flow/`，
前端從 `raw.githubusercontent.com/<repo>/data/momentum_flow/web/` 讀取（`latest.json`、`history.json`、`backtest.json`）。
本功能是**流程**，不進策略庫；頁面只用「符合、未符合、資料不足、條件觸發、曝險上限、部位試算」等用語。

## 隔離
- 既有程式碼、資料格式、樣式一律唯讀；只改兩處既有檔案：探索頁入口卡片＋路由（只新增），`data.yml` 在既有步驟之後追加一個
  `continue-on-error` 的計算步驟（`python -m pipeline.momentum_flow update`）。
- 前端任何錯誤只影響本頁（`DataState`）；入口卡片在摘要失敗時顯示「—」。自動化測試環境（`navigator.webdriver`）在第一次成功開過本頁之前（localStorage `tmf-momentum-seen`）不替本功能發外部請求（既有冒煙測試要求沒有 console error、也不該依賴外部網路）；一般瀏覽器一律讀取。
- 輸出路徑：`momentum_flow/snapshots/{YYYY}/{YYYYMMDD}.json.gz`（每日快照）、`momentum_flow/web/*.json`（前端）、`status.json`。

## 每日更新流程
| 台北時間（交易日） | 補抓那一棒取得的資料 | 動能流程 |
|---|---|---|
| 15:02 | 收盤行情、指數 | 第一次算出 T：K5 當日判「資料不足」（注意／處置名單約 17:00 才公布），所以篩出通常是 0，頁面漏斗下方會說明 |
| 16:02 | 三大法人 | 重算（「漲多投信買」參考標記用到投信） |
| 17:02 | 外資持股；同一棒的「其他來源」抓注意／處置名單 | 名單取得 → K5 可判定，篩出清單在這之後才有意義 |
| 22:02 | 融資融券、借券、當沖；再抓一次名單 | 最後一次重算（名單若在 17:02 之後才公布，這次會更正） |

- 觸發條件：data.yml 在 `run` 之後的步驟，這一棒有新資料（`deploy=true`）才執行；每日任務（daily／catchup，含接力）與排程的週期任務（週六集保、每月 11 日月營收）都會跑；手動回補、5 分 K、接續回補不跑。逾時 20 分鐘只中止這一步，`commit-data` 照常提交既有資料。
- 名單是否已取得：看 manifest 的 `daily_extras.at`（每日任務其他來源最後一次執行時間）是否在當天 17:00 之後（`params.lists_publish_time`）；之前的日子一律視為已取得。
- 快照：窗口內沒有的日子補寫，最近 5 個交易日（`params.rewrite_recent_days`）每次都重算，收盤後陸續補進的資料會反映到快照；寫入是原子的、gzip 時間戳固定，內容沒變時資料分支不會多出差異。
- 前端每次開頁都重新驗證（`cache: 'no-cache'` ＋ `?d=日期`），raw.githubusercontent.com 本身約 5 分鐘快取；service worker 不攔截跨網域請求。

## 共同定義（實際使用的公式）
| 項目 | 定義 | 來源 |
|---|---|---|
| 股票池 | 上市櫃普通股（載入時已排除 ETF、ETN、受益憑證、存託憑證；特別股與興櫃不在行情來源內）、當日有收盤價、不是全額交割／管理股票（逐日標記） | `evidence.data.from_dataset`、`full_delivery_mask` |
| 基準日 T | 資料中最後一個有收盤價的交易日 | `meta` 行情 |
| 還原價 | 指標效度評估同一套還原價（含息、已處理分割）；報酬、均線、52 週高點用還原價；漲停、成交金額、試算股數用未還原價 | `evidence.data` |
| R_n | 還原收盤(t) ÷ 還原收盤(t−n) − 1；窗口沿用 App：1M＝21、3M＝63、12M＝252 個交易日 | `evidence.indicators.ret` |
| RS | 0.4 R63 + 0.2 R126 + 0.2 R189 + 0.2 R252 的全市場普通股百分位（個股頁同一定義） | `indicators.rs_raw` + `cross_pct` |
| PR_n | R_n 的全市場普通股百分位：(平均名次 − 0.5) ÷ 有效檔數 × 100 | `derive.momentum.cross_pct` 同一公式 |
| MA_n | 還原收盤的 n 日簡單平均（個股）；大盤狀態用加權股價指數（非報酬指數）的 60／240 日簡單平均 | |
| 主族群 | 既有細產業層：優先沿用個股資料的主要細產業標示（`Layers.fine_of` 第一個，個股頁「細產業」第一個就是它）；沒有標示時取成員數最少的細產業（成員數相同取名稱排序第一） | `derive.sectors.build_layers` |
| 族群 3M 中位數 | 主族群全部成員 R63 的中位數（成員 ≥ 3 檔才算；K3 兩邊都用 63 日） | |
| 月營收生效日 | 次月 10 日（法定期限）；沒有各公司逐月公布日的歷史，沿用指標效度評估的 `revenue_table`；最新值超過 45 天視為無值 | `evidence.data.revenue_table` |
| 漲停 | 沒有官方漲停價：收盤較前一日收盤 ≥ 9.5% 視為漲停；回測的開盤漲停／跌停也用 ±9.5% | |
| 注意／處置 | 處置：公告日 ≤ t ≤ 處置迄日（含當日公告）；注意：當日公告。兩種名單都有資料的第一天起才可判定（注意名單自 2023-06） | `raw/twse_disposition`、`raw/twse_attention` 等 |
| 三態 | 符合＝1、未符合＝0、資料不足＝−1；任何需要的數值缺少就是資料不足 | |

## 大盤狀態機
- raw：收盤 > MA60 且 > MA240 → 1；MA60 ≥ 收盤 > MA240 → 2；收盤 ≤ MA240 → 3；均線不足 → 0（資料不足）。
- eff：第一個有效 raw 當天初始化；raw 比 eff 差時當天降級；要升級須最近 10 個交易日每天都有 raw，且其中最差的 raw 仍優於目前 eff，升到那個最差值；raw 為 0 時沿用前一日。
- 曝險上限：1＝100%、2＝60%、3＝30%；升級倒數＝10 − 已連續優於 eff 的天數（只在 raw 優於 eff 時顯示）。
- 輸出近 250 個交易日的 收盤／MA60／MA240／raw／eff（`history.json`）。

## 候選池與檢查清單
- A：最近 40 個交易日（含 T）「營收高帶量」觸發過（策略庫 `rev_confirm` 同一定義：營收一年高事件日、收盤上漲、量比 ≥ 1.5、RS_ev ≥ 70）；
  B：非 A 且 40 日內「營收一年高」（`rev_high12`）；C：非 A、B 且 RS ≥ 85、最新月營收年增 > 0。策略訊號用指標效度評估的 universe 與 `cs_percentile`（與策略庫一致）。
- K1 85 ≤ RS ≤ 97（A 級下限 80）；K2 PR12M ≥ 80 且 PR3M ≥ 60；K3 族群 3M 中位數 > 0 且 R63 > 中位數；K4 收盤 > MA60 且 ≥ 0.8 × 近 250 日還原最高價；
  K5 不在處置、不在注意、20 日內漲停 < 2；K6 20 日平均成交金額 ≥ 5,000 萬元。上市櫃未滿 250 個交易日 → K2、K4 資料不足。
- PR1M ≤ 30 只標示「近月回檔」；「漲多投信買」（策略庫 `combo_rs_trust`）40 日內觸發只供參考。
- 清單：篩出＝全符合；新觸發＝T 全符合且 T−1 未全符合（含資料不足）；差一項＝恰 5 項符合、1 項未符合（有資料不足者不列）。
  排序：A → B → C、PR12M 降冪、RS 降冪、代號升冪。

## 持股條件監看（瀏覽器端，唯讀「我的股票 › 持股」）
- D1：T−2、T−1、T 都 還原收盤 < MA60。D2：未還原收盤(T) ≤ 0.85 × 成本 × f(進場日)，f＝進場日還原因子 ÷ T 日還原因子；沒有進場日 f＝1 並標示「未調整除權息」。
- 檢查日 R＝每月 10 日（含）之後第一個交易日；M1 RS(R) < 70；M2 最新年增 < 0 或 ≤ 前 3 個月年增平均 − 15 個百分點（3 個月任一無值＝資料不足）；M3 主族群 3M 中位數(R) < 0。
- 權重 > 20% 提示；70 ≤ RS(T) < 85 緩衝區只標示；PR1M 不觸發；另顯示今日是否仍全通過。
- 個股的 R 日與 T 日數值由 `latest.json` 的 `stocks` 表提供（每檔：RS、年增、族群中位數、D1 位元、全通過、收盤）。

## 回測（規格第九節）
見 `pipeline/momentum_flow/backtest.py` 模組說明：t 收盤決策、t+1 未還原開盤執行（±9.5% 視為漲跌停順延；進場順延 5 日取消）；
每個 R：M1–M3 出場、權重 > 20% 減回 1/N、依排序填滿可用名額（每名額＝淨值 ÷ N，同族群 ≤ 3 檔、≤ 35% 淨值）；
每日 D1／D2 出場、eff 降級依 RS 由低到高出場、升級不立即加碼；成本 0.1425% × 0.28 雙邊、證交稅 0.3% 出場；不計最低手續費；
基準 0050 還原含息、等權股票池（前一日在股票池的股票等權、收盤到收盤，不扣成本）。
濾網效度：每個 R，P＝全通過、F_k＝只有 Kk 未通過；前瞻＝還原收盤(R+21) ÷ 還原開盤(R+1) − 1；每期 mean(P) − mean(F_k)，取平均並算 Newey-West t（lag 1）；有效期數 < 30 標「樣本不足」。

## 資料不足的範圍與已知限制
- K5 需要注意名單（2023-06 起）：之前的日子 K5 一律資料不足，因此沒有「全通過」，回測與濾網效度實際從 2023-06 之後的檢查日開始。
- 族群成員用目前的產業分類（沒有歷史分類）；主族群中位數與族群上限在歷史快照中都用目前分類。
- 月營收生效日用法定期限（次月 10 日）；實際多數公司提前公布，訊號會比實際晚幾天。
- 上市櫃不足 250 個交易日：K2、K4 資料不足。上市櫃天數從資料起點（2016-09）起算，評估窗口（最近 3 年）內一律足夠。
- 回測不計最低手續費、不計滑價；股數以未還原開盤整數股計算（含零股）。
