## 本次回補

### 月營收 2015-01～2023-05（來源優先序：MOPS → FinMind）
1. **MOPS 月營收彙總表**（`mops_revenue`，官方）：本開發容器被 MOPS 阻擋（`mopsov.twse.com.tw` 307 → 「因為安全性考量，您所執行的頁面無法呈現」；`mops.twse.com.tw` 亦同），
   因此改用 GitHub Actions 的 Data workflow（`task=backfill, source=mops_revenue, start=2015-01-01, end=2023-05-31`，run #95，2026-10-01 18:31 UTC 觸發，ref main）。
   每月 2 次請求（上市、上櫃），依禮貌爬取 3–5 秒間隔，約 101 個月 × 2 ≈ 202 次。結果寫入 data 分支 `raw/revenue/{YYYY}/{YYYYMM01}.csv.gz`，只補不存在的月份。
   **注意**：這次 backfill 的待續槽會取代原本「法人、信用 2015-01-01～2023-09-06」的待續槽（2016-11-17 以後已完成；2016-09-01～11-16 尚未回補，影響：法人類指標的訊號期間從 2016-11 起而不是 2016-09）。
2. **FinMind `TaiwanStockMonthRevenue`**（合法公開 API，免費等級每小時 300 次）：本容器逐檔抓取（2,112 檔普通股，含已下市；每 12.5 秒一次、被限流時退避重試），
   依最近成交值由大到小排序，抓回的資料用 `scratchpad/convert_finmind.py` 轉成與 MOPS 相同的欄位（營收千元、月增、年增、累計由自身序列計算；`note` 註明 FinMind）。
   **只寫 MOPS 沒有的月份**；與 MOPS 重疊的月份用來交叉比對（下表）。結果：抓到 276 檔（成交值最高的 276 檔）後停止——
   MOPS 已補齊 2015-01 起全部月份，FinMind 沒有需要寫入的月份（`written 0`），只用於交叉比對。
3. **可得日**：兩個來源都沒有各公司的實際公布日 → 一律用法定期限（次月 10 日）；FinMind 的 `date` 欄（公布月的 1 日）不採用。
