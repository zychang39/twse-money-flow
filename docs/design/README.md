## 設計系統摘要

- **Tokens**：`web/src/styles/tokens.css` 是唯一來源（色彩、5 級字級、4pt 間距、圓角、陰影、光暈、動畫時長與緩動）。
- **色彩預算**：灰階為主；紅漲綠跌只給漲跌；琥珀只給風險；電光藍只給可互動元素。資金環境不用紅綠燈，改為「積極／中性／保守」，只有保守用琥珀。
- **環境光**：今晚頁＝資金環境（有風險琥珀、其餘中性灰藍）；我的股票與個股頁＝主角數字所選期間的漲跌（與走勢線同一期間、同一顏色，切換時一起淡入淡出）；其他頁面不使用。靜態漸層、不做即時模糊；設定可關閉（即 A「夜間簡報」），減少透明度／減少動態效果時自動退回。
- **字體**：中文用系統字體；數字與英文用自託管 Inter（拉丁子集、預載），全站等寬數字。
- **介面行為參數**：`config/ui.yml`（變化門檻、燈號彙總、冷靜卡條件、回測可信度、XP 與徽章）。
