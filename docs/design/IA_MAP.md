# 資訊架構對照：舊頁面 → 新位置

底部導覽是一條膠囊內 5 格（ROUND4 起：今晚、我的股票、探索、搜尋、紀律，搜尋在第 4 格），每個畫面都先說明自己在回答「每晚 5 分鐘儀式」的哪一個問題：

| Tab（只有線條圖示） | 回答的問題 | 網址 |
|---|---|---|
| 今晚（月亮） | ①大盤環境能不能積極？②我的持股有沒有出事？③自選股出現了什麼新變化？④我該記錄或檢討什麼？ | `#/` |
| 我的股票（走勢線） | ③自選股有什麼新變化（預設）、②持股有沒有出事 | `#/mine`（自選）、`#/mine?seg=hold`（持股）、`#/stock/:code` |
| 搜尋（第 4 格） | 找一檔股票、加入自選 | `#/search` |
| 探索（指南針） | ①大盤環境的延伸研究、③自選以外的新機會（次要層級） | `#/explore/*` |
| 紀律（同心環） | ④我該記錄或檢討什麼？ | `#/discipline/*` |
| 右上角頭像 | 第一列深淺色（深色／淺色／跟隨系統），其下設定、備份、資料健康、方法說明 | `#/me/*` |

舊網址（書籤、Telegram 日報連結）會自動轉址到新位置（`web/src/router.ts` 的 `legacyRedirect`）。
